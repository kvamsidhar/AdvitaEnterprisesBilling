ADVITA ENTERPRISES — QUOTATION GENERATOR

REQUIREMENTS
- Windows 10/11
- Python 3.10 or newer (64-bit recommended)
- Internet connection and a Gemini API key for AI item generation

INSTALL
1. Extract the entire ZIP into a folder.
2. Double-click setup.bat and wait for installation to finish.
3. Double-click launch.bat to open the Tkinter application.
4. Enter your Gemini API key in the app.
5. Choose the quotation language, enter customer details, and describe the goods/services.
6. Click "Generate items with Gemini". Review/edit every line and price.
7. Click "Preview quotation" to open the PDF and review it before printing.\n8. After reviewing, return to the app and click "Print quotation" to confirm and send it to your default printer.\n9. Use "Export quotation PDF" if you also want to save a permanent copy.

NOTES
- The supplied blue quotation image is used as the PDF background.
- PDF output uses the supplied template's existing company branding and layout.
- The language dropdown guides AI-generated item descriptions. Fixed labels in the provided background image remain in English.
- Gemini-generated prices are estimates and must be checked before issuing.
- GST defaults to 18%; change it to the applicable rate.
- The API key is used locally by the app and is not saved to a file by this program.
- If PDF text placement needs adjusting for your printer/template, edit the coordinate values in app.py in _make_pdf().
\nPREVIEW AND PRINT\n- The app opens a PDF preview before enabling its Print quotation button.\n- Printing asks for confirmation first. On Windows, automatic printing depends on your default PDF viewer's print handler; if it does not print, use Ctrl+P in the opened PDF viewer.\n
